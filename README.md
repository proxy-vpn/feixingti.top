- **一键导入**：Clash / Shadowrocket / V2Ray / sing-box 订阅一键导入，节点列表自动同步；
- **多端通用**：电脑、手机、平板共用一条订阅，实际并发设备数以套餐标注为准；
- **性价比档位**：入门档位即买即用，月付起售，满意再续，不强制年付；
- **不夸大承诺**：不写「绝对解锁 / 永不掉线」，晚高峰表现以你自己的时段实测为准。

## 三步用起来

1. 在面板注册账号，选个入门档位，付款后即时开通；
2. 复制专属订阅链接，粘贴到客户端的订阅 / Profile 里更新；
3. 选个延迟低的节点，开启系统代理或 TUN 模式即可使用。
